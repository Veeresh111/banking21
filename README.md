# Banking App

[![CI](https://github.com/Veeresh111/banking-app/actions/workflows/ci.yml/badge.svg)](https://github.com/Veeresh111/banking-app/actions/workflows/ci.yml)

Full-stack banking app with a React frontend and a Node/Express backend.

## Structure
- `frontend/` React app
- `backend/` Node/Express API

## Development
1. Install deps in `backend`: `npm ci`
2. Install deps in `frontend`: `npm ci`
3. Run backend: `npm run dev`
4. Run frontend: `npm start`
